Documentation ¶

Overview ¶

Package wire is the byte level of the ESCP protocol: the 32-byte packet header, the type-length-value elements, the catalogue of TLV types, and the RC4 and RSA primitives that protect them. It knows nothing about settings, sockets or switches.

The package is internal to the escp package: the settings code in the parent package and the fake switch in escptest use it, nobody else, and nothing here is a stable interface. The meaning of the numbers is documented in ../../PROTOCOL.md.

Packets are untrusted input. Unmarshal bounds-checks every length it reads and returns an error for a truncated or inconsistent packet; it never panics.

func RSASessionTLV ¶ 

func RSASessionTLV(key []byte) []byte

RSASessionTLV encrypts the session key (textbook RSA, no padding) and returns the 10-byte TLV 528 value: 00, word count, 4 little-endian words.

func ReverseBytes ¶ 

func ReverseBytes(b []byte) []byte

ReverseBytes returns b reversed: the RSA operands travel little-endian.

func Unmarshal ¶ 

func Unmarshal(b []byte) (Header, []TLV, error)

Unmarshal decodes a packet. It validates the header and the TLV lengths and never reads beyond the buffer.

TLV is one type-length-value element.

type TLVType ¶ 

type TLVType int16

TLVType is the number that says what a TLV holds (the catalogue below). Comparing or passing a plain number as a type is a compile error. 

const (
	TLVModel          TLVType = 1
	TLVHostname       TLVType = 2
	TLVMAC            TLVType = 3
	TLVIP             TLVType = 4
	TLVNetmask        TLVType = 5
	TLVGateway        TLVType = 6
	TLVFirmware       TLVType = 7
	TLVHardware       TLVType = 8
	TLVDHCP           TLVType = 9

	TLVLED            TLVType = 12
	TLVAutoSave       TLVType = 13 // 1 = configuration changes are saved automatically (1 byte)
	TLVFactoryDefault TLVType = 14

TLV types of the ESCP protocol, as used by this client. The catalogue is the one place that maps a number to its meaning; the settings code in the parent package owns the layout of each value.
