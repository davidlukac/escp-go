### Overview ¶

Package wire is the byte level of the ESCP protocol: the 32-byte packet header, the
type-length-value elements, the catalogue of TLV types, and the RC4 and RSA
primitives that protect them. It knows nothing about settings, sockets or
switches.

The package is internal to the escp package: the settings code in the parent package
and the fake switch in escptest use it, nobody else, and nothing here is a stable
interface. The meaning of the numbers is documented in ../../PROTOCOL.md.

Packets are untrusted input. Unmarshal bounds-checks every length it reads and returns
an error for a truncated or inconsistent packet; it never panics.

      func RC4Session ¶

      func RC4Static ¶

RC4Static encrypts or decrypts (RC4 is symmetric) with the vendor utility's static key.

      func RSAModulus ¶

RSAModulus returns a copy of the 64-bit public modulus of the key exchange.

      func RSASessionTLV ¶

func RSASessionTLV(key []byte) []byte

RSASessionTLV encrypts the session key (textbook RSA, no padding) and
returns the 10-byte TLV 528 value: 00, word count, 4 little-endian words.

      func ReverseBytes ¶

func ReverseBytes(b []byte) []byte

ReverseBytes returns b reversed: the RSA operands travel little-endian.

      func Unmarshal ¶

func Unmarshal(b []byte) (Header, []TLV, error)

Unmarshal decodes a packet. It validates the header and the TLV lengths and never
reads beyond the buffer.

      type TLVType ¶

type TLVType int16

TLVType is the number that says what a TLV holds (the catalogue below). Comparing or passing a
plain number as a type is a compile error.

TLV types of the ESCP protocol, as used by this client. The catalogue is the one
place that maps a number to its meaning; the settings code in the parent package
owns the layout of each value.

const (
	// TLVPorts is the Port Setting page: one 7-byte entry per port.
	TLVPorts TLVType = 4096

	TLVIGMPEnabled     TLVType = 4352 // snooping enabled (1 byte)
	TLVIGMPGroups      TLVType = 4353 // learned groups, repeated 10-byte entries
	TLVIGMPSuppression TLVType = 4354 // report message suppression (1 byte)

	// TLVLAG is Switching > Port Trunk: one TLV per group, group id (1 byte) and member port mask (4 bytes).
	TLVLAG TLVType = 4608

	// TLVVLANMTU is VLAN > MTU VLAN: 2 bytes (enabled, uplink port).
	TLVVLANMTU TLVType = 8192
